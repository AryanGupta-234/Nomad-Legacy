Spotify Integration

    
Free, takes about 2 minutes — this only lets NOMAD read public track/playlist info, never your account or plays.


    

      

      

        
Connected 

        
Credentials verified and working

      

      
    


    

      
1Go to developer.spotify.com/dashboard and log in with any Spotify account (free tier is fine).

      
2Click Create app. Name it anything (e.g. "NOMAD").

      

        3
        For Redirect URI, paste the box below — required but unused here.
          

            http://127.0.0.1:8765/
            
          

        
      

      
4Save, open the app, click Settings, and paste the Client ID and Client secret below.

    

    

      
      
    

    

      
      
    

    

    

      
      
    


    

      
Full-track playback (optional)

      

        The Client ID/Secret above only reads metadata — Spotify's terms don't allow full audio through that. Full-track playback works differently: it streams through Spotify's own player in this browser tab, using your own Premium login, via the official Web Playback SDK. NOMAD's backend never receives or stores the audio.
      

      
5Requires a Spotify Premium account — free accounts can't use the Web Playback SDK.

      

        6
        Back in your Spotify Developer app's settings, add this exact URL under Redirect URIs (in addition to the one above), then Save:
          

            this app's URL + /api/spotify/callback
